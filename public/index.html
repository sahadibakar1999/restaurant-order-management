⚙️ Connecting Official Meta WhatsApp Cloud API

The system includes a fully functional WhatsApp Simulator for immediate local testing. When you are ready to connect a real phone number for customer orders via Meta WhatsApp Cloud API, follow these three simple steps:

Step 1: Meta Developer App

Create an app at developers.facebook.com > Select "Business" type > Add the WhatsApp product.

Step 2: Configure Webhook URL

Expose your server port (e.g. using ngrok or deploying to Render/AWS) and enter the webhook URL in Meta App > WhatsApp > Configuration:

https://<your-domain>/webhook
Verify Token: RESTAURANT_ORDER_BOT_SECRET_2026

Step 3: Subscribe to "messages" webhook field

Under Webhook fields, click Subscribe for messages. Now every customer scanning the table QR code will interact with this bot!
